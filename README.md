# AI Engineering Lab

A hands-on repository for learning and building **AI Engineering applications with Python and LangChain**.

This repository is not intended to be a collection of copied tutorials. Each concept I learn is followed by an implementation, experiment, or practical project to understand how AI applications are actually designed, built, evaluated, and improved.

The primary focus is **building AI applications while learning**, with a strong connection to my background and interests in **Data Engineering, data systems, and AI/ML**.

---

## 🎯 Purpose

The goal of this repository is to move from:

**Learning concepts → implementing them → building applications → evaluating them → improving them**

Instead of learning AI Engineering only through courses, I use this repository as a practical laboratory where I turn concepts into working software.

## 🔨 Build-While-Learning Approach

Each learning topic follows a practical cycle:

```text
Learn a concept
      ↓
Understand the architecture
      ↓
Implement a small experiment
      ↓
Build a practical application
      ↓
Test and evaluate
      ↓
Document what was learned
      ↓
Improve the implementation
```

The objective is not simply to complete courses.

The objective is to develop the ability to **design and build AI systems independently**.

---

## 🚀 Project Philosophy

Projects in this repository should answer at least one of these questions:

- Can this AI concept solve a real problem?
- How does this architecture work in practice?
- What are its limitations?
- How can its reliability be evaluated?
- How can it be integrated with data systems?
- What happens when the system is exposed to real-world data?
- How can the application be improved?

Small experiments are welcome, but the long-term goal is to turn useful experiments into complete applications.

## 🧪 Experiments vs Projects

Not everything in this repository is intended to be production-ready.

### Experiments

Small implementations used to understand a specific concept.

Examples:

```text
prompt experiments
retrieval experiments
embedding experiments
tool-calling experiments
agent experiments
evaluation experiments
```

### Projects

Larger applications that combine multiple concepts into a usable system.

Examples may include:

```text
RAG applications
AI data assistants
AI documentation systems
SQL assistants
data profiling assistants
agentic data workflows
```

This distinction makes it clear which code exists primarily for learning and which code represents a more complete application.
